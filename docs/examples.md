# Example Menu Configurations

These examples are based on the configuration examples distributed with the plugin. They are documentation samples; compare with the files generated by your installed version if options differ.

## Native text menu

```yaml
# Example menu WITHOUT any textures: only native dialog buttons and text.
# Open it with /servermenu or /dm open example

title: "<gold><bold>Server Menu"
commands: [servermenu]
can-close-with-escape: true
columns: 2              # buttons per row

body:
  - type: text
    text:
      - "<gray>Welcome, <white>%player%<gray>!"
      - "<gray>Players online: <green>%online%"
    width: 300
  - type: space
    lines: 1
  # shown only to players with this permission / when the condition is true
  - type: text
    text: ["<red>You are an operator."]
    permission: "sdialogmenus.admin"

buttons:
  - label: "<green>Spawn"
    tooltip: "<gray>Go to spawn"
    width: 140
    actions:
      - "[sound] entity.experience_orb.pickup 1 1"
      - "[player] spawn"
  - label: "<aqua>Rules"
    tooltip: "<gray>Show the rules in chat"
    width: 140
    actions:
      - "[message] <yellow>1. Be kind  2. No cheating"
  - label: "<gold>Daily reward"
    tooltip: "<gray>Runs a console command"
    width: 140
    actions:
      - "[console] give %player% diamond 1"
      - "[title] <gold>Reward!;<gray>You got 1 diamond"
      - "[delay] 40"
      - "[actionbar] <green>Enjoy!"
  - label: "<red>Admin tools"
    tooltip: "<gray>Only for admins"
    width: 140
    permission: "sdialogmenus.admin"
    actions:
      - "[open] games"

exit-button:
  label: "Close"
  width: 150
```

## Texture menu

```yaml
# Game selector with texture banners (needs the resource pack, see config.yml).
# Without the pack the same menu shows as plain clickable text.

# Logo as title (texture from the textures folder). Remove these 4 lines to use a text title.
title-texture: logo.png
title-height: 48        # displayed height in GUI pixels
title-ascent: 16        # how far the logo sits above the title baseline
title-left-pad: 28      # offsets the client's warning button so the logo stays centred
title: "<gold><bold>Hoplite"   # used when there is no pack

commands: [games]
open-on-join: true
join-delay-ticks: 20
can-close-with-escape: false
body-extra-width: 24    # extra width for the text area (too small = banners wrap and break)

# Optional camera spot behind the menu. Stand where you want it, run /dm setcamera arena,
# then set enabled: true and /dm reload.
background:
  enabled: false
  camera: arena
  restore-on-select: true

body:
  - type: banner
    texture: battle_royale.png
    height: 54                    # displayed height; keep it a multiple of 9 for tight rows
    hover: "<gray>Click to play"
    fallback: "<white><bold>Battle Royale</bold> <gray>- Last one standing wins <green>%server_battleroyale% playing!"
    overlays:                     # live text drawn on top of the banner
      - text: "<green>%server_battleroyale% playing!"
        line: 1                   # line inside the banner (0 = top, each line is 9px)
        align: right
        x: 6
    actions:
      - "[sound] entity.experience_orb.pickup 1 1"
      - "[message] <green>Joining <white>Battle Royale</white>..."
      - "[server] battleroyale"
  - type: banner
    texture: duels.png
    height: 54
    hover: "<gray>Click to play"
    fallback: "<white><bold>Duels</bold> <gray>- Fight 1v1 with any kit <green>%server_duels% playing!"
    overlays:
      - text: "<green>%server_duels% playing!"
        line: 1
        align: right
        x: 6
    actions:
      - "[sound] entity.experience_orb.pickup 1 1"
      - "[server] duels"
  - type: banner
    texture: zombie_survival.png
    height: 54
    hover: "<gray>Click to play"
    fallback: "<white><bold>Zombie Survival</bold> <gray>- Survive the horde together <green>%server_zombies% playing!"
    overlays:
      - text: "<green>%server_zombies% playing!"
        line: 1
        align: right
        x: 6
    actions:
      - "[sound] entity.experience_orb.pickup 1 1"
      - "[server] zombies"

exit-button:
  enabled: true
  label: "Disconnect"
  width: 150
  actions:
    - "[kick] <gray>You left the server."
```

## Canvas / layout menu

```yaml
# Canvas layout example: six textures placed freely, each with its own click action.
# This example and its tpl_a.png through tpl_f.png textures are installed automatically.
# Run /dm reload and then /layout to open it.
#
# Rules: x / y / height are in GUI px; y and height should be multiples of 9 (one text line = 9 px).
# Each PNG is drawn at 2x: displayed size = png size / 2. "slice: true" keeps full quality for wide images.

title: "<gold><bold>Layout test"
commands: [layout]
can-close-with-escape: true
body-extra-width: 24

body:
  - type: canvas
    width: 401              # minimum canvas width; it grows if an item reaches further
    items:
      - texture: tpl_a.png  # A: small left
        x: 0
        y: 0
        height: 36
        slice: true
        hover: "<gray>Button A"
        fallback: "<white>A"
        actions: ["[message] <green>You clicked A"]

      - texture: tpl_b.png  # B: small right
        x: 205
        y: 0
        height: 36
        slice: true
        hover: "<gray>Button B"
        fallback: "<white>B"
        actions: ["[message] <green>You clicked B"]

      - texture: tpl_c.png  # C: wide
        x: 0
        y: 45
        height: 36
        slice: true
        hover: "<gray>Button C"
        fallback: "<white>C"
        actions: ["[message] <green>You clicked C"]

      - texture: tpl_d.png  # D: medium (left)
        x: 0
        y: 90
        height: 54
        slice: true
        hover: "<gray>Button D"
        fallback: "<white>D"
        overlays:
          - {text: "<yellow>%online% online", line: 4, align: right, x: 8}
        actions: ["[message] <green>You clicked D"]

      - texture: tpl_e.png  # E: tall (right, spans D and F rows)
        x: 270
        y: 90
        height: 99
        slice: true
        hover: "<gray>Button E"
        fallback: "<white>E"
        overlays:
          - {text: "<gold>Tall", line: 5, align: center}
        actions: ["[message] <green>You clicked E"]

      - texture: tpl_f.png  # F: medium (bottom left)
        x: 0
        y: 153
        height: 36
        slice: true
        hover: "<gray>Button F"
        fallback: "<white>F"
        actions: ["[message] <green>You clicked F"]

exit-button:
  label: "Close"
  width: 150
```

## Main configuration reference

The default configuration shipped with the plugin is shown below. Preserve valid YAML indentation when editing it.

```yaml
# sDialogMenus - config.yml
# Menus live in plugins/sDialogMenus/menus/*.yml, textures (PNG) in plugins/sDialogMenus/textures/.
# See README.md for the full menu format.

# How often (seconds) proxy player counts (%server_<name>%) are refreshed
count-refresh-seconds: 5

# ---------------------------------------------------------------------------
# Resource pack (only needed by menus that use textures; menus with plain
# buttons/text work without any pack). The pack is generated automatically from
# the PNG files in the textures folder every time the plugin loads / reloads.
  # Output: plugins/sDialogMenus/pack/sDialogMenusPack.zip
# ---------------------------------------------------------------------------
resource-pack:
  enabled: true

  # single = use one glyph when possible; images wider than 256px are auto-sliced.
  # sliced = cut textures into slices (full quality, any width).
  # Images taller than 256px are scaled down to fit the font atlas.
  # (can be overridden per menu element with "slice: true/false")
  texture-mode: single
  slice-width: 200          # slice size in px for sliced mode (max 256)

  # --- how players get the pack (choose ONE) ---
  # A) your own direct download link (upload plugins/sDialogMenus/pack/sDialogMenusPack.zip).
  #    Put the SHA-1 printed by "/dm pack info" into "sha1" (empty = use the built pack's hash).
  url: ""
  sha1: ""
  # B) built-in web server: set host.enabled true, open the port in your firewall and put your
  #    public IP or domain in public-address. (Leave "url" empty.)
  host:
    enabled: false
    port: 8123
    public-address: ""

  force: false              # true = players who decline the pack are kicked
  prompt: "<gray>Loads the menu graphics"
  hide-warning-button: true # makes the client's warning icon in dialog titles invisible
  # Must match the Minecraft client resource-pack format you target.
  # 64 is for older 1.21.x clients; check and update it when targeting newer versions.
  pack-format: 88
  description: "sDialogMenus"
  # Files you put in plugins/sDialogMenus/pack-extra/ are added to the pack unchanged.
```
