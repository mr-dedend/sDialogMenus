# Documentation Contributions

This repository contains user-facing documentation only. Plugin source code and compiled binaries are intentionally not stored here.

## How to contribute

1. Open an issue describing the correction or missing information.
2. For a documentation change, submit a pull request with a clear summary.
3. Keep examples consistent with the released plugin version.
4. Do not include server logs containing IP addresses, tokens, or private data.
5. Do not claim compatibility with a Minecraft/Paper version unless it has been verified.

When documenting new options, test the example against the corresponding released plugin before submitting it.
